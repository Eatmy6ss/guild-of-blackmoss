## 一、M0 要回答的两个问题

M0 不是"做游戏"，是**消灭最大风险**。两周只回答两个问题，其余一切让路：

1. **手动模式好玩吗？** —— 实时团长指挥台（集火/阵型/道具/撤退/路线）在真实战斗里能否产生"每 30–60 秒一个有意义决策"（设计宪法 KPI）。这是全项目最大的设计赌注：如果指挥台不好玩，核心身份坍塌，越早知道越好。
2. **循环有引力吗？** —— 通关一次后，是否想立刻再来一把（换配装、搏更高难度）？刷子游戏的生命线。

### 验收标准（两条硬线）

- **硬线 A**：你（制作人）在零开发者干预下，完成一次 15 分钟完整会话：招募 → 编队 → 手动下本 → 团灭或通关 → 分装备 → 再出发。
- **硬线 B**：M0 结束时你的结论是"我明天还想打开它"，或者能明确说出哪里不对。

## 二、技术栈（我的职责范围，向你汇报）

| 项 | 决策 | 一句话理由 |
|---|---|---|
| 语言/构建 | **TypeScript + Vite** | 模拟密集型项目的正确工具；类型系统保护数值代码 |
| 界面 | **DOM（React）** | 公会管理是 UI 密集型游戏，DOM 表格/面板/按钮的效率碾压游戏引擎 UI |
| 战斗演出 | **PixiJS（自研轻量战斗引擎）** | 模拟与演出分离：底层是确定性数值结算，Pixi 只做表现；不需要 Phaser 的物理等重装 |
| 运行环境 | 开发期纯浏览器；**Steam 打包（Tauri/Electron）推迟到 M2 决策** | 不影响架构，届时选轻者 |
| 素材 | 占位美术：色块像素小人 + 通用图标（Q9 已锁：目标像素风，M1 前统一换皮） | 车轮先滚起来 |

**架构铁律从第一天生效**：职业/性格/词缀/boss 机制/掉落表全部是**数据表**，不是硬编码——"路线图功能扩展不返工"的物理形态。挂机与手动共用同一套决策系统，执行者不同（Q27 红利）。

## 三、范围

### 做（In）
- **1 个副本**（3 人本，2 个 boss，1 条岔路）
- **3 职业**：守卫（前排承伤）/ 牧师（治疗）/ 游侠（输出），轻协同词条 2 条（Q13）
- **团长指令台**：集火目标 / 阵型（推进·收缩·分散）/ 团队药（治疗药·爆发药）/ 撤退令 / 岔路抉择
- **boss 机制 5 种**（见映射表）
- **掉落与配装**：boss 固定掉落表、词条随机 roll、3 装备槽、战力重算
- **招募**：三选一候选，天性（属性倾向）+ 性格（简化版：勇猛/谨慎/贪婪/忠诚 四轴）
- **永久死亡 + 撤退保护开关 + 纪念堂占位**
- **挂机模式**：同一循环 AI 代打（性格 stub：谨慎=早撤退保守路线；鲁莽=搏宝箱），分配 roll 点
- **公会战术手册占位**：打过某 boss → 之后全队对它小幅增益（熟练度双层制的公会用哪个半边）

### 不做（Out，M0 阶段明确排除）
关系系统 · 需求/士气/工资 · 公会大事层 · 会长声望 · 基地建筑 · 爬塔 · 多副本 · 词缀副本难度分档 · 离线累积 · 卡片分享 · 音频 · 正式存档（用 localStorage 会话级顶替）· 肖像美术 · 10 人团本 · 自由点兵（M0 只做固定队，混合编队在 M1 拆开）

## 五、boss 机制 ↔ 团长指令映射（提案，按 Q32/审计承诺交付）

| 机制 | 团长对策 | 失败惩罚 |
|---|---|---|
| 前摇 AOE（红圈预警） | 阵型→**分散** | 超额伤害 |
| 读条强化/治疗 | **集火**（攒伤断条） | boss 回血/获得增益 |
| 召唤增援 | 集火**切换优先级** | 数量压制、牧师被切 |
| 束缚 + 追击窗口 | **撤退时机赌博** / 驱散药 | 减员风险 |
| 狂暴软墙（时限） | **爆发药时机** | 拖入必败局 |

惩罚梯度：M0 阶段（普通本级）失败 = 超额伤害与士气打击，**不允许真实死亡**（死亡教育放在有保护系统就位的 D11 之后）。H 本/爬塔的致死惩罚 M1 实装——与设计宪法一致。

## 六、你的角色（试玩节奏）

- **Week 1**：只在 D7 上线一次（约 15 分钟），回答一个问题："**战斗看得懂吗？**"
- **Week 2**：每天一个构建 + 一个具体问题，每场 15–30 分钟：
  - D9："撤退令紧张吗？集火有用吗？"
  - D10："掉装备那一下爽吗？"
  - D11："死人的时候你心疼吗？"
  - D12："挂机代打可信吗？"
  - D14：完整验收会话（硬线 A/B）
- 反馈格式：**随便说话**。"感觉不对""这里烦""这招没用"都是合格反馈，翻译成数值/机制改动是我的活。
