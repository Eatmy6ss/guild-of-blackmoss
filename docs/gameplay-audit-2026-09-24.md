# 黑苔公会：玩法审查与功能对齐报告

审查日期：2026-09-24。代码基准：`761de24`，本地分支 `feature/shldo-dev`。

本报告用于协作讨论，不代表已经批准的新设计。本次未修改游戏代码。

审查依据：当前数据表、模拟逻辑、界面调用、设计文档；查看大厅、花名册和基地；另用独立浏览器来源的新档检查首场战斗、休整和路线选择；对版图解锁、路线、高塔血量和掉落做了定向逻辑复现。没有完整通关全部副本，也没有完成长期经济、全部职业组合或胜率测试。历史文档中的胜率和验收数字不作为本次实测结果。

**总体判断**

这是一个已有较完整系统骨架的公会远征原型：玩家招募和培养队员，通过编队、装备、战斗指令和路线选择取得收益，同时承担英雄永久死亡的风险。它已经具备继续做深的内容基础，但玩家看到的规则、实际效果和设计文档之间存在明显差距。

最有价值的组合是三条并行成长线：英雄变强、共同远征形成默契、反复探索积累地图知识。最需要解决的不是增加更多系统，而是让玩家的选择准确生效，并清楚感知收益和代价。

暂定讨论基准：公会养成为主、关键时刻指挥为辅，普通远征以 5—10 分钟为目标。这是审查假设，等待用户确认。

**一、核心玩法与玩家角色**

正常循环：招募与整备 → 选择副本和初始路线 → 自动普攻/自动释放职业技能 → 玩家切阵型、集火、用药或撤离 → 战间休整与选路 → 获得装备、金币、经验和熟练度 → 回城处理招募、事件、培养与建设。

长线循环：基础队伍 → 第一版图主线与支线 → 五人团本 → 第二版图 → 高塔纪录与构筑优化。第二版图解锁目前存在缺口，不能把这条顺序当作已完整实现的流程。

玩家扮演的是会长和战场指挥者。角色技能目前自行施放，玩家不逐个操纵角色移动，也不手动操作完整技能栏。用“团长指挥”描述现状，比“动作战斗”准确。

十五混合职阶均有运行数据和训练场入口，不是全部封存：圣盾使、游猎卫、裂阵者、符文骑士、缚魂卫、咒印手、辉光法师、契灵祭司、战地牧者、魔弓手、蚀箭手、游击刃、战斗法师、血武士、咒火术士。

精进池共28个候选条目，各专精二选一或三选一；当前每个专精选过后不能在该入口重选。通用战技是五个永久可叠加被动，没有装备槽位竞争，因此更接近长期养成，而不是需要舍弃另一项的构筑选择。

构筑深度不能只按“12＋15”计数。许多技能复用重击、群攻、嘲讽等效果，身份文案比机制差异更丰富。建议用阵容解决的问题检验价值：例如反伤队对多段近战有优势，召唤队改变承伤分配，诅咒队围绕集火窗口，火抗配装适应灼热环境。上述阵容优劣尚未批量验证。

种族和职业规则目前不统一：招募候选路径考虑种族可用职业；开局生成器没有同样限制，本次原页面中出现了血精灵守卫；训练场列出所有混合职阶，切换未统一检查种族及来源职业。需要确认限制究竟是世界观硬规则，还是仅影响招募概率。

**六、玩法层面的主要风险（判断，不等于已证实的平衡缺陷）**

1. **死亡奖励与珍惜人物的目标可能冲突。** 每名阵亡者给普通远征全队＋2%伤害，按人数累加无显式上限，同时获得祝福、保留装备，缺员又能免费等访客。可能形成牺牲新人换长期收益的动机。建议先测实际收益/耗时，再讨论光环封顶、纪念品质或以生平成就决定遗产。
2. **技能与装备的“数量”尚未完全转成玩法差异。** 18词缀只有8种属性方向，多条只是同属性不同数值区间；所有角色按槽位穿装备，无专属装备限制，也未见套装件数判定。建议先让少量构筑有清楚的适用敌人和代价。
3. **长路线可能制造重复操作。** 单条路线约10—15段，第一版图每图4—5组敌人、第二版图每图2组，重复在所难免。需要测整次远征时长、有效决策数和重复波次数；本次首战观察不能推断全游戏平均节奏。
4. **成长会被动态缩放部分抵消。** 高等级回低级副本会推高敌方血攻，同时降低经验收益。若核心承诺是“培养后能轻松处理旧威胁”，这种缩放需要克制，并在界面解释。
5. **士气、关系目前更像轻量数值层。** 胜利＋6士气、常规继续前休整＋10，会较快抵消单次死亡冲击；遗弃关系函数未看到外部接入。系统有故事入口，但尚不具备需求、日常活动、长期关系冲突等完整人物模拟。
6. **事件选择未形成完整成本契约。** 金币负结果被截断到0，选项没有统一支付条件；“醉汉的地图”文本写50金，选项结果却未扣费。许多事件最终主要改变金币与士气，世界状态变化较少。建议先让文本成本、实际资源和延迟结果一致。
7. **保存规则与永久死亡存在张力。** 进行中的远征和高塔不保存，刷新回到此前公会状态。它可以是明确的宽容设计，也可能削弱死亡承诺；应由用户决定，不应悄悄改成更严苛模式。
8. **新手引导弱于功能密度。** 开局已是Lv5，基地同时展示大量锁住的混合职阶和被动。目标列表先排列所有Boss首杀，成长与招募目标在后；建议把“第一次集火—第一次选路—第一次换装—第一次培养”变成渐进引导。

**八、建议的建设顺序与验收标准**

第一阶段：恢复选择与反馈的一致性。处理F01—F11中影响流程/奖励的部分，优先路线、招募、高塔和挂机。验收应包含：点哪条路进入哪场；新档进不了第二版图；候选入职前后专精一致；建筑升级可观察到数值变化；事件药水实际到账；高塔正确带入剩余血量；自动模式完成一轮、回城并再出发。

第二阶段：把第一版图打磨成完整体验。补渐进教学、近程目标和掉落追踪；以同等资源比较手动与挂机、不同阵容与专精；记录远征时长、决策次数、撤退率、死亡率、药水支出、升级和熟练度轮次。先明确指标，再扩展内容。

第三阶段：形成可复玩的内容差异。为副本分配教学主题、怪组搭配和定向战利品；为事件增加地域/前置/冷却/后续限定；让第二版图火抗、吐息和龙威要求玩家调整阵容或配装。新增内容须回答“玩家需要做什么不同决定”。

第四阶段：长期经营与人物故事。确定死亡奖励边界、祝福获取方式和存档宽容程度，再扩展关系、非战斗特性、公会生活或保卫战。否则新系统会建立在尚未稳定的经济和损失规则上。

**九、需要与用户逐项确认的设计方向**

| 对齐项 | 建议起点 | 尚待确认的选择 |
|---|---|---|
| 第一主体验 | 公会养成＋关键时刻指挥 | 是否更偏硬核操作或人物故事模拟 |
| 普通远征时长 | 5—10分钟，以有效决策而非波次数充时长 | 是否接受10—20分钟或更长 |
| 永久死亡 | 保留，但保证风险可预判、失败可恢复经营 | 是否允许远征中退出回滚，是否保留无上限死亡光环 |
| 构筑方向 | 阵容协同、技能机制和少量有明显用途的装备 | 混合职阶是否任意跨系；是否严格执行种族限制 |
| 挂机定位 | 已熟悉内容的减负，重要抉择可暂停接管 | 是否要自动处理事件与无限连刷；何时应自动停止 |
| 第二版图价值 | 新机制和配装取舍优先 | 继续T2横向扩展，还是T3/T4数值换代 |
| 人物故事范围 | 先做因果正确的事件和可回顾的生平 | 何时投入需求、生活、声望与关系网络 |
| 近期协作范围 | 先修规则一致性，再做首轮体验 | 用户负责玩法/内容，还是也承担核心系统修改 |

这些是待讨论项，并非要求一次回答全部。建议先确定主体验与远征时长，再对齐死亡、构筑、挂机和世界扩展。
