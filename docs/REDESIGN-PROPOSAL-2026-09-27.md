# 整体重构提案（2026-09-27）

> **状态：提案，未经制作人采纳，不构成宪法修订。** 讨论用稿。
> 前提：制作人定位澄清——「本质是 RPG；反复刷副本与爬塔（大秘境）为核心玩法；带局外养成／公会经营」，且**高塔＝大秘境，与副本是两类内容，不可同质化**；目标接近「高塔为主菜」，但**副本也必须有难度与惩罚**。
> 本提案不新增引擎级系统，绝大部分复用已实现的机制引擎、创伤、保险、熟练度、委托与建筑。

---

## 〇、一句话结构

**副本是准备，高塔是证明，公会是维持。**

三个场所必须承担三种**不同性质的压力**，否则它们会互相替代。当前设计的核心问题不是某个系统做得不好，而是三者压力同质（都靠数值），于是副本变成没有代价的刷、高塔变成更难的副本、公会经营变成一堆被动加成。

---

## 一、三层压力模型

| | 副本（远征） | 高塔（大秘境） | 公会（基地） |
|---|---|---|---|
| 内容形态 | 作者设计、有限、有叙事 | 无限阶梯、随机词缀 | 状态管理 |
| 玩家的问题 | 「我够不够格」 | 「我敢走多远」 | 「我能不能持续出勤」 |
| 惩罚 | **损耗**（精力／创伤／补给／天数） | **死亡**（真的，不可逆） | **名册枯竭** |
| 节奏 | 反复、可挂机 | 一次一赌、**绝不可挂机** | 以「天」为单位 |
| 产出 | T1–T2 装备、金币、经验、材料 | T3、星髓、最高层记录 | 能力上限 |
| 失败形态 | 空手而归 + 队伍报废数日 | 失去人 + 失去本趟全部战利品 | 无人可派 |

一句话定调：**副本的惩罚不是「你死了」，是「你下一次出不了勤」。**

---

## 二、副本：如何有难度与惩罚，又不破坏「反复刷」

### 2.1 出勤状态（本提案的支点）

每名英雄新增 **精力（0–100）**：

- 出征按战斗场次、受创程度、远征天数消耗精力
- 精力低 → 属性衰减、创伤判定概率上升、士气下滑更快
- 恢复只能靠**天数**（休息／宿舍／酒馆加速）

这一条机制一次性解决了当前六个悬空问题：

| 现存问题 | 精力如何解决 |
|---|---|
| G03 主力／替补成长差距 | 主力必须休息 → 替补必须上场 |
| 三人打天下、名册无意义 | 被迫维持 8–12 人可轮换阵容 |
| 建筑只是被动加成 | 宿舍／酒馆变成出勤能力的杠杆 |
| 招募没有真实需求 | 名册厚度成为刚需 |
| 「天」这个资源没有竞争 | 休息与出征争抢同一资源 |
| 无脑连刷低级图 | 连刷会把队伍刷废 |

**没有这一条，公会经营层永远是装饰。** 这是全提案优先级最高的新增机制。

### 2.2 出征补给（经济的下水道）

每次出征预付成本：口粮（人数 × 天数）＋ 药水 ＋ 装备维护费。

- 低级图净收益变薄 → 刷老图不再是无风险套利
- 直接回应 R01「金币长期溢出」，且不必削减卖装收入
- 「带几个人去」成为真决策（五人本成本显著高于三人本）

### 2.3 撤退不再免费

现状：撤退保护兜底 ＝ 失败零代价，副本因此没有「输」的体感。

改为：撤退保住性命，但 **本次远征收获全部丢失 ＋ 额外精力惩罚 ＋ 触发创伤判定**。

死亡仍然不会发生（除非玩家自选，见 2.4），但失败开始有重量。

### 2.4 悬赏加码：副本版的「钥匙层数」

接副本时可自选加挂条款，可叠加，奖励乘算。这是让副本拥有难度阶梯、同时不污染「反复刷」体验的关键——**难度由玩家主动出价，而不是系统强加**。

| 条款 | 约束 | 奖励 | 设计意图 |
|---|---|---|---|
| 急行军 | 限制总轮次 | ×1.3 | 逼出爆发与集火效率 |
| 轻装 | 不可携带药水 | ×1.4 | 考验容错与治疗配置 |
| 带新人 | 必须带 1 名低于队伍均等级 5 级者，且其不可倒下 | ×1.5，该员双倍经验 | **把练替补变成玩法** |
| 深潜 | 必须走完整路线，禁用直捣 Boss | ×1.3 | 保护路线内容的价值 |
| 不设防 | 关闭撤退保护，本次开启永久死亡 | ×2.0 | **把死亡风险的选择权交还玩家** |

两条重点：

- **「带新人」** 把 G03 从待测量问题变成核心玩法。练替补不再是苦工，而是有风险有回报的护送任务，并立刻让玩家关心替补的装备——公会经营由此活起来。
- **「不设防」** 让副本能死人，但只在玩家自己签字时。这比系统强加的死亡有分量得多。

### 2.5 熟练度迷雾的新出口

现设计的终点「满熟练解锁直捣 Boss」与「反复刷」方向相反——它奖励重复的方式是**消除变数并允许跳过内容**。调整为：

- **第 1–10 遍**：揭迷雾，学地图（保留现设计，体验良好）
- **满熟练后**：「直捣 Boss」保留，但降级为**低收益快速通道**（只给 Boss 掉落，不给沿途材料与经验），用于赶委托进度
- **完整收益必须走全程**，而全程可挂 2.4 的加码条款

熟练度因此既奖励重复，又不吃掉玩法。

## 三、高塔＝大秘境：从「更难的副本」改造成「赌局」

### 3.1 当前实现的四个缺口

读 `src/sim/tower.ts` 所见：

1. 内容池只取黑苔／锈坑（版图一），作为终局内容过薄
2. 纯线性缩放（每层 +15% 血／攻），无任何局内变数
3. **奖励逐层立即入账** → 没有任何「赌」的张力，塔沦为线性刷
4. 允许挂机爬塔，靠压胜率区分手动价值
5. （次要）`settleTowerFloor` 使用 `Math.random()`，脱离项目的确定性 RNG 纪律

### 3.2 词缀层（大秘境的灵魂）

每 3 层为一「段」，进段时随机挂 1–2 条词缀，层数越高词缀越多。

词缀全部复用已有机制引擎，**几乎零新增引擎工作**：

| 词缀 | 复用 |
|---|---|
| 灼热 | `env: 'heat'` 已实现 |
| 增援加倍 | `summon` 机制已实现 |
| 治疗减半 | 治疗乘区已存在 |
| 残血开局（每场 80% 血） | 战斗初始化 |
| 提前狂暴 | `enrage` 参数化 |
| 精英额外机制 | `mechanics` 数组追加 |

同一批怪，这周要分散躲火、下周要抢打增援——**变数是刷子游戏的燃料**，而这正是当前塔完全缺失的东西。

### 3.3 下塔才结算（本节最重要）

将「逐层立即入账」改为 **战利品累计、下塔方才兑现；团灭则损失大部分**。

这一处改动把塔从「刷」变成「赌」：每个 Boss 层结束时，玩家面对一个真实决策——

> 当前累计：4 件装备、2 星髓、1800 金
> 下一段词缀：灼热 ＋ 增援加倍
> 队伍状态：坦克 31% 血，牧师精力见底
> **继续深入，还是带着东西下塔？**

「何时收手」应当被做成戏剧性时刻，而不是一个「继续／离开」按钮。这是塔全部乐趣的来源。

配套：**高塔保险**从「阵亡装备免赎回」扩展为「团灭时保住部分累计战利品」，它由此成为赌局中的对冲工具，而不是一个边缘的钱坑。

### 3.4 内容池扩展

随层数解锁全部版图的怪组与 Boss 轮换（纯数据工作）。深层应当出现玩家在版图二才见过的机制组合。

### 3.5 塔禁止挂机

**塔是「证明」，不可代打。** 挂机只允许刷已通关的副本。

这让 G04（手动 vs 挂机的价值）从一个需要靠数值平衡反复验证的问题，变成结构上已分开的非问题。

### 3.6 死亡的统一原则（建议入宪法）

> **全游戏不存在「骰子杀死了我的角色」。每一次永久死亡都是玩家决策的后果。**

- 塔中阵亡 ＝ 你自己多爬了那一层
- 副本中阵亡 ＝ 你自己签了「不设防」

这条原则让永久死亡可以既残酷又不引发玩家怨恨，是「英雄是会死的人」能够成立的前提。

## 四、公会层：KPI 从「战力」改为「可持续出勤人数」

建筑重新分工，每座建筑对应出勤能力的一个维度：

| 建筑 | 新职责 |
|---|---|
| 宿舍 | 名册上限、精力恢复速度 |
| 酒馆 | 招募质量与频率、士气恢复、怪癖压制（已有） |
| 疗养所 | 创伤治疗成功率与速度（已有） |
| 训练场 | 替补追赶主力（经验补正、精进层解锁） |
| 铁匠铺 | 装备维护费下调、重铸、分解 |
| 纪念堂 | 死者遗产（英灵光环，已有） |

**「天」是主时间资源**，所有行为争抢同一池子：出征要天、休息要天、治疗要天、建设要天、王国委托有期限。经营层的决策密度由此产生。

## 五、新核心循环

```
公会晨会：查看名册状态（谁可出勤／谁在养伤／谁精力见底）
  ↓
定目标：副本悬赏（选图 ＋ 挂加码条款） 或 入塔（下注）
  ↓
编队：受出勤状态约束——不是自由挑选最强三人
  ↓
战斗：指挥（招牌技能 ＋ 阵型 ＋ 集火 ＋ 药水）
  ↓
战果：装备／金币／经验   ⊕   损耗：精力／创伤／士气／补给
  ↓
公会消化：疗养、休息、训练、招募、建设——全部消耗「天」
  ↓
回到晨会
```

与旧循环的唯一结构性差异，是多出了 **损耗 → 消化** 这一段。**这一段就是公会经营游戏的本体。**

## 六、情感核心的三层落地

「英雄不是棋子，是会死的人」需要日常实体，不能只靠死亡兑现：

1. **他会累** —— 精力。你得安排他休息，于是你每天都在看着他（**新增，且最日常**）
2. **他会留疤** —— 创伤。他身上带着历史（`scars.ts` 已实现）
3. **他会死** —— 但只在你贪的时候，或你签字的时候

羁绊不是靠死亡建立的，是靠**日常照料**建立的；死亡只负责把它兑现。当前设计缺的正是第 1 层。

## 七、实施顺序

### 阶段 0 · 地基（不加新玩法）
- 机制注册表重构（连带根除 B01／B02 及整类接缝缺陷）
- 难度模型：单一标量生成敌人数值，取代分散手调（G01／G02 的根解）
- `RunState` 状态机提取出 App.tsx（连带解决 R04）

### 阶段 1 · 让战斗值得重复
- 英雄招牌技能（12 专精各一个，团长可点名释放）
- 高塔词缀层（复用已有机制引擎）
- 高塔改为下塔结算 ＋ 保险扩展为战利品对冲

### 阶段 2 · 让公会经营成立（可与阶段 1 并行）
- 精力／出勤系统
- 出征补给成本
- 撤退代价
- 建筑职责重新分工

### 阶段 3 · 让副本有阶梯
- 悬赏加码系统
- 熟练度接新出口
- 高塔内容池扩展

### 建议砍掉或降级
- 混合职阶回归：继续 dormant
- 套装系统：阶段 3 之后
- 声望／10 人本／公会保卫战：维持挂起
- **停止继续扩写事件表**（`guild-events.ts` 已 2110 行）：转投创伤／关系系统，让内容由模拟长出而非手写

## 八、资产保全清单

本提案**不废弃任何已实现系统**。对照现状：

| 现有资产 | 处置 |
|---|---|
| 12 专精 / 6 种族 / 六维 | 保留，专精增加一个招牌主动技 |
| 装备纪元 / 威能 / 星髓 / 遗物赎回 | 全部保留 |
| 创伤系统 | 保留并**升格为涌现支柱主干** |
| 高塔保险 | 保留并扩展职责 |
| 熟练度迷雾 | 保留，改接新出口 |
| 逐段选路 | 保留 |
| 王国委托 | 保留，作为叙事主线脊柱（内容质量高） |
| 事件表 | 保留现有量，停止扩写 |
| 纪念堂 / 编年史 / 统计 | 保留 |
| 建筑系统 | 保留，重新分工 |

新增机制仅四项：**精力、补给成本、加码条款、塔词缀**。其中只有精力需要新的存档字段与 UI，其余三项基本是既有数据结构的重新组合。
