## 本轮实际修复

`sellValue` 原先用ID字符串猜装备阶级，`-line-` 一律算T3，招牌和龙系不含阶级的ID落入T1。它们在装备表中均有T2条目，导致同阶装备卖价与新遗物赎回费错位。

现在统一读取 `ITEM_BASES[baseId].tier`。白色无词条的职业剑和矿监铁壳均卖90金，原先分别135/45金。品质、词条、铁匠铺加成和赎回倍率保持原样；已持久化的遗物报价不重写。没有修改通关收益、药价或掉率。

全底材×白绿紫回归覆盖卖价、加成卖价、普通/高塔赎回价。独立浏览器5196用UI导入专用测试档，两件T2均显示90金，依次出售后2000→2090→2180，刷新保留库存0与销售统计180；浏览器错误为空，未动真实玩家存档。

## 工具与实验边界

```sh

```

每组四个起点，每个起点20个模拟公会，各最多刷20趟：

- 黑苔Lv5/单件T1起步；灰烬Lv7/单件T1；荆棘和隘口Lv11/三槽T2。这些是各阶段夹具，不是一个新档从头自然养成至版图二。
- 初始150金或1000金、零祝福、3/3药水、人类默认专精；按地图实际3/5人编制。花名册ID在升级前固定，以防全局生成序号影响初始成长对照。
- 连续保留经验、默契、装备、金币、药水、伤亡、创伤、治疗熟练度与遗物。复用真实战斗、掉落、首杀保底、升级、死亡、疗养和定向招募函数；不凭空补资源。
- 每次回城按预算补员、治疗、宴会、补药和赎回；换装使用职业加权面板评分，超过1%才换，其余变卖。它忽略部分技能/威能价值，不是最优构筑；“换装次数”不等于已证明的有效战力提升。
- 缺员或士气不足且当前策略无法恢复时停止。没有免费访客、委托、离线收入、随机事件、节点替换、建筑、心愿和首杀手册战斗增益，**停止不等于游戏软锁**。尤其没有退回低图恢复的策略。
- 手动模式是每5tick执行站位、集火、55%血线用药及狂暴时爆发的机器人，不代表真人熟练操作。自动和手动保留相同保护开关。
- 每个模拟公会断言期末金币＝期初＋战斗/通关＋卖装－补给－治疗－招募－赎回/宴会，金币不得为负，战斗超时直接失败。默认组在另一个进程重跑得到完全相同结果。

## 可以和不可以得出的结论

1. 固定旧图难度后，这些自动策略样本能通过掉装/升级/默契持续获益；稳定旧图累计金币很多。因为没有投资建筑等开销，不能据此立刻削减收益。
2. 隘口低现金队在首次伤亡后有恢复风险；提高现金只部分改善，不能仅靠统一增加金币解决，也不能把150金起点冒充完成版图一的真实资产。
3. 指挥机器人明显弱于当前自动策略，尤其困难地图。保留这个失败结果；在改进指挥策略或真人试玩之前，不得宣称手动开荒价值已经达标。
4. 黑苔样本没有死亡、没有额外祝福来源，期末仍有未治创伤。这暴露了疗养对祝福来源的依赖，但未模拟委托/事件，不能声称玩家必须送死换祝福。
5. 最长换装空窗只衡量当前评分策略；尚未把替换装备的价值通过同队实战反事实对照验证。
