- 引擎主线：TypeScript + React + PixiJS + Vite；`src/sim` 纯逻辑（可单测）/ `src/data` 数据表 / `src/ui` 表现 / `src/state` 存档，加内容不动引擎。
- 存档 v12：MIGRATIONS 逐级迁移链（v1→v12 全程可走）；游戏内导入导出面板（SaveTransferPanel，带校验预览）；离线收益（零工金币）。
- 验证链：`npm run verify` 37 门禁（esbuild+smoke+生产构建）；E2E 三脚本（大厅/战斗/高塔，CDP 驱动）；qa-playthrough 新档全流程巡检；diag 三件套（控制台/资源/单位）。
- 协作文档骨架：AGENTS（AI 上岗须知+制作人红线）/ HANDOFF（每轮交接）/ BACKLOG / DECISIONS / 本文件。

### 战斗与远征（P01 定调：这是核心循环）
- 确定性战斗：createBattle 带 seed；五职业攻速分化；四阵型、集火、治疗/爆发药、撤退令、自动保护、暂停、×10 tick 快进、挂机代打+自动连刷、战斗画面放大（battle-mode）。
- 12 座副本两版图：黑苔荒野 6（含 5 人团本荆棘要塞）+ 龙脊山脉 6（含 5 人团本龙渊之心）；14 只 Boss 全部 DCSS 精细帧+专属机制（双指令/召唤/治疗咏唱/吐息/龙威/灼热地形 env:heat）。
- 路线系统：routePlan 生成器（Boss 恒压轴+wave 池拉长，险路 12-15 段/稳路 10-12 段，精英节点 ×1.25）；逐段选路（风险/报酬标注）；熟练度迷雾 12/24/36 三档解锁（含直达 Boss）。

### 成长与装备
- 三路径招募（免费访客/120 金定向悬赏/220 金+5 祝福三选一）+冷却+缺人保底；六职业十二基础专精十五混合职阶，Lv6 精进池，五项通用战技。

### 经营与表现
- 基地五建筑三级；经济三资源（金币/英灵祝福/药水×2）+变卖/庆功宴/训练/药水采购。
