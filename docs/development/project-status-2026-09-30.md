## 1. 项目是什么

- **黑苔公会(Guild of Blackmoss)**:像素风佣兵公会管理游戏。买断制单机,未上线。TS + React + PixiJS + Vite(Tauri/Steam 暂缓)。
- **设计宪法北极星**:"明天想继续打开玩的冲动"。基因:矮人要塞式涌现叙事 + 巫师 3 式两难事件 + 半自动战斗(玩家干预);竞品《公会创世纪》仅 ~10% 轻度参考。宪法已冻结(C1),决策走 DECISIONS(U 序列)。
- **组织形态(本项目最大特色)**:制作人(设计拍板)+ 多 AI 协作施工——本机 Codex(施工)+ zcode(独立复审/部署/市场分析)+ 云端 shldo(GPT 驱动)+ Claude(设计 grill 伙伴)。协作介质=git + AGENTS.md 红线 + HANDOFF/BACKLOG/DECISIONS;代码必经独立 AI 复审 + PR。
- 仓库 GitHub private(防设计窃取;副作用=GitHub Pages 线上试玩下线,试玩走本地 5173)。

## 5. 已知短板与风险(诚实清单)

1. **卖点未收敛**:有方向(干预感/涌现叙事/延迟后果事件)但尚无一句能写上商店页、且被陌生人验证过的卖点;系统清单里还没有"倒吸凉气"时刻。
2. **真人验证为零**:全部信号是内证(制作人+协作者 AI)。Pages 下线后连线上试玩的最便宜试金石也没有。这是最大缺口。
3. **卖相无记忆点**:DCSS 素材功能性合格,UI 是开发者审美;拍不出"会讲故事"的商店截图。
4. **数值/构筑底子薄**:8 种威能多为布尔开关,2 种纯数值;数值系统薄弱是制作人自认(C4 冻结中,批次 2 规则化改造)。
5. **内容量长跑短板**:87 事件撑不起第三个月;说书人层是复利器但待拍板。
6. **数值倒挂挂账**(C4 冻结不修):锈坑 1.05<黑苔 1.125、熔铸 2.727<火脊 2.799。
7. **未做全职业胜率/自然养成/长期经济验收**(各 PR 交付边界一致声明)。
8. **品味单点**:设计仪表高度依赖制作人一人;AI 协作放大执行力但方向感不可替代。

## 6. 市场参照(2026-09-30 局外人分析)

- **赛道成立**:Steam 买断制"佣兵队伍经营+涌现叙事"圈层有实证——Loop Hero 首周 50 万/累计 100 万+;Wartales EA 期 60 万;Battle Brothers 约 85 万份/$11.7M 流水(3-4 人团队)。三款共享 affinity 圈层,玩家互相迁移;中文侧太吾绘卷/鬼谷八荒证明 sim+涌现的中文胃口。本作的像素/公会/两难/创伤/编年史正落在此画像内。
- **撤退正确**:刷子市场饱和(D4/PoE2/Last Epoch 三座大山),制作人主动转向"词缀遭遇×战前博弈"差异点。
- **结构性优势**:成本≈0(多 AI 协作,无薪金/引擎费),break-even 极低——1 万份×$15 即显著回报;真正风险在发现性(demo/主播/Next Fest)而非需求。
- **分享物缺口**:社区的"物件/仪式/语言"连接件未建(战报卡/说书人/词缀命名),已入待拍板池。
