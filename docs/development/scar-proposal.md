# 创伤系统(Scar System)设计提案 · 讨论稿

2026-09-25。制作人构思:"把远征、爬塔的后果加进人物特性——战斗中受到精神损害,就是永久的属性值减少;可以花钱或资源通过酒馆、医院等设施恢复(永久性、不可逆的损伤无法恢复)。参照矮人要塞、暗黑地牢、环世界。"

**状态:构思 grilling 中,未拍板,未实装。** 本文档 = 设计拆解 + 推荐方案 + 待拍板问题。

## 一、为什么这个构思值得做(价值分析)

1. **补齐因果链的"活着的一半"**:现在远征的代价只有死亡(永久)+士气(临时)。活着回来的人毫无痕迹——创伤系统让"活下来"也有故事,直接服务硬线 B(涌现叙事)
2. **和现有系统严丝合缝**:
   - **士气=心情**(临时,喝酒就好);**创伤=心结**(持久,要疗养)——两级心理后果,目睹死亡先扣士气、概率留创伤
   - **K09 特性互动**:怕黑的人进墓园创伤概率更高;爱喝酒的人可以借酒压制怪癖
   - **K02 纪念品质咬合**:带着创伤和残缺死去的英雄,生平评分更高——创伤反而让人物"值得记住",负面扭成叙事资产
   - **K10 经济出口**:疗养/压制 = 金币与祝福的持续消费口(呼应经济盘点:支出口全是一次性的痛点)
3. **阵容决策加深**:带伤出征?花钱治疗?换替补?——每次出征多一层"人的考量"

## 二、推荐方案:三层创伤(分期落地)

### 第一层 · 属性创伤(可恢复)
- 某属性 -1~2(六维里的维度,恐惧→精神 / 断骨→体质 / 旧伤→力量 / 手抖→敏捷)
- 恢复:**疗养所**(建筑已有,正好给疗养所加消费者)——花金币+祝福,确定性恢复一条(费用 = 重招募的 ~40%)
- 触发口只有三个:被 boss 机制命中(恐惧/灼烧/束缚)、濒死体验(血量<15% 收场)、目睹队友死亡(士气冲击时概率转化)——**普通掉血零风险**,纪律见第四节

### 第二层 · 心理怪癖(行为层,可压制不可根治)
- 怪癖不扣属性,改**行为**:怕火(灼热地形士气流失加倍)/ 夜惊(塔内休整回复减半)/ 嗜酒(庆功宴对个人效果翻倍,但上阵时士气上限 -10)/ 沉默(默契获取 -1)
- 酒馆"借酒消愁":花金币压制一条怪癖 N 天(临时失效,不治本)——暗黑地牢式
- 治愈怪癖的唯一方式:**完成一次心愿**(K06)或**首杀 boss**(用荣耀盖过恐惧)——涌现叙事的闭环

### 第三层 · 永久残缺(不可逆,低概率,带补偿印记)
- 重伤截肢级:"独臂"(力量 -3,防御习惯 +1)/"烧瞎眼"(幸运 -2,听风辨位 +2)——**代价换小特质**,环世界式
- 概率极低(濒死体验且治疗失败等复合条件),每名角色终身最多一条
- **K02 联动**:带残缺的阵亡者纪念品质评分大增——残缺是传奇的注脚
- 数值纪律:残缺总属性惩罚 ≥3 但 ≤4,确保"残而不废"

## 三、触发模型草案(待拍板后细化)

| 来源 | 概率基准(草案) | 创伤类型 |
|---|---|---|
| 被 boss 机制命中(恐惧/灼烧/束缚/拉拽) | ~10% 每次命中 | 属性创伤为主 |
| 濒死收场(该场结束时个人血量 <15%) | ~25% | 属性创伤 / 低概率残缺 |
| 目睹队友死亡(已有 death-shock) | ~20% | 心理怪癖为主 |
| 高塔深层(6 层+)每层结算 | ~5% 叠加 | 混合,深层偏怪癖 |
| 团灭幸存者 | 必定 1 条 | 混合 |

**纪律**:全部概率集中在 sim 层常量,smoke 断言"普通远征(无濒死无死亡)创伤率 = 0"——掉血不能出创伤,防止挫败滚雪球(暗黑地牢的核心教训)。

## 四、数值纪律(红线)

1. 量级:创伤 = 半级损失(每级属性 +3,创伤 -1~2),痛但不废人
2. 恢复费 < 重招募的 50%:养伤比换人划算,系统才有意义
3. 每人创伤上限 3 条(满了不再新增——"要么愈合要么疯掉"的极端状态不做)
4. 永久残缺概率单独封顶:全公会每 20 场远征 ≤1 条的期望值

## 五、落地分期建议(拍板后)

- **一期**:属性创伤 + 疗养所恢复(数值层,工程最小,先验证"活着回来也有代价"的体感)
- **二期**:心理怪癖 + 酒馆压制 + 心愿治愈闭环(行为层)
- **三期**:永久残缺 + K02 品质联动(叙事层)

## 六、待拍板问题

1. **分层档位**:三层全量 / 双层(无残缺)/ 单层先行?(推荐三层分期)

3. **恢复经济**:疗养所定价(重招募的 40%?)、怪癖压制时长与费用
4. **永久残缺的补偿印记**:要不要"独臂但防御 +1"式的补偿(环世界式),还是纯惩罚
