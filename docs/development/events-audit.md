# 事件主题贴合度审计（2026-09-25）

制作人反馈："事件的制作和选取一定要贴合这个游戏的主题，不要什么事件都写进去。"（源自试玩中撞到官府税吏类事件）
本文件 = 全量重审结论 + **今后的事件创作规范**（shldo/GPT 写新事件前必读）。

## 一、主题标准（黑苔世界观的"贴合"定义）

核心主题：**边疆佣兵公会的生存史诗**——刷本成长、委托为生、英雄会死、故事留下。

贴合的事件题材（任占其一即可入选）：
1. **佣兵生态**：委托、雇佣、竞争公会（灰隼/铁棘）、阵亡与纪念、招募与队内人情
2. **边疆生存**：黑苔荒野的村镇、沼泽、矿道、白霜、野兽与怪物威胁
3. **超自然怪谈**：遗迹、诅咒、契约、亡者叙事（涌现叙事是宪法级精髓）
4. **世界观势力**：修道院（英灵信仰）、军镇、灰冠王国（K01）、鳞音教（龙脊）——以**佣兵视角**触碰
5. **公会经营**：金币/药水/声望的取舍，酒馆生态

不合格的题材（一票否决）：
- 现代官僚/职场话术移植（"请律师""合理规避""KPI"式幽默）
- 与佣兵身份无关的纯市井琐事
- 无两难结构的纯赠礼/纯惩罚事件
- 无法落到黑苔地名/势力的悬空奇幻

## 二、本轮移除（6 个，93→87）

| ID | 标题 | 移除原因 |
|---|---|---|
| levy-clerk | 税吏的账本 | 现代官僚喜剧（"比请律师便宜"），官府横税题材气质出戏 |
| tax-warrant | 第二幕·刺头的代价 | levy-clerk 的延迟链，随主事件移除 |

| drunk-map | 醉汉的地图 | 与 old-map（酒鬼的旧地图）同质，二者留一 |

**存留观察**（下轮试玩反馈再定）：`tax-convoy`（税官的车队）——同为官府题材，但视角是"佣兵接单"（伏击车队 or 给税官当镖师），两难结构好，暂留。

## 四、新事件创作规范（2026-09-25 起）

1. 新事件提交前过一遍上面"主题标准"五条，写明该事件落在哪条
2. 优先与现有系统联动：副本名/高塔/熟练度/王国信任/编年史——"涌现叙事"优先于孤立小品
3. 两难每个选项必须有代价面（金币/士气/装备/延迟后果至少占一），禁止纯赚选项
4. 文案体例：引号用「」、金额用汉字（五十金/一百二十金）、地名用黑苔世界观词表
5. 数量不追求 100+：**每个事件都要立得住**，同质题材先合并再新增
