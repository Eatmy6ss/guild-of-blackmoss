## 难度递增改版（2026-09-25 制作人拍板，b638b88 已交付并部署）

反馈"随便刷刷就全刷完了、难度曲线不平滑"——五杠杆已落地，**后续开发以此为新数字契约**：
1. expectedLevel：4/5/6/7/8/10 → **5/6/7/8/9/11**（荆棘要塞=版图一毕业考，全图数值顶点）
2. 敌人数值：杂兵 HP 中值 399→1736（约 3.1 倍跨图）、攻 7→24、防 4→10；Boss 同系数缩放（相对强度 5-6.5× 杂兵不变）
3. 经验：波 16/boss 90 → **波 11/boss 60**——契约"一副本刷 5-6 遍升一级"（smoke ⑩ 断言 0.08）
4. 熟练度：12/24/36 → **35/60/80**（≈3/5/6.5 遍解锁类型揭示/全揭示/直捣 boss）
5. 节奏带（smoke ⑲）：杂兵 7-40s、boss 下限 12s、毕业考上限 70s；验收机器人配 T2 三件套（难度递增后装备=入场券，裸装不再是真实玩家下限）
6. 实测曲线：杂兵 8.5→25→27.7s，毕业考 15→22→34→39→**52.9s（荆棘）**单调递增，12 图全 8/8 可达
**注意**：老档玩家会立即感到变难（期望中的效果）；若试玩反馈过难，优先微调 TUNING 系数表（图 4-6），勿回退曲线结构。
