## 1. R5.1 副本层:风险要有回报(U33①–④)

### 1.1 地形回报

风险地形在掷路况的同时,**当场给一样好处**。中性地形没有风险也没有回报。

| 地形 | 当场回报(进入节点时) | 可能挂上的路况 |
|---|---|---|
| 水域 | 本节点掉落率 ×1.5;非战斗节点有 25% 捞到 1 件装备 | 湿透 |
| 林野 | 本节点熟练度收益 ×2 | 迷途 |
| 墓地 | 祝福 +2 | 阴寒 |
| 营地 | 额外回复 15% 生命 | 暴露 |
| 道路 / 地下 / 废墟 / 圣所 / 熔岩 | —(圣所解阴寒、营地解湿透照旧) | — |

- 回报在地图悬停框里和路况风险**并列显示**,遵守揭示档位:档 0 只看到地形,档 2 起看到回报与风险的具体数字。
- **每个副本至少 2 种风险地形**。下表是 Claude 的默认补法,沿用各副本主题;制作人可以否决:

| 副本 | 现有风险地形 | 补 |
|---|---|---|
| rustmine 锈坑矿道 | 营地 | 水域(暗河涌水) |
| ashfield 灰烬旧战场 | 墓地、水域、营地 | (加圣所:残破礼拜堂,用来解阴寒) |
| scalehaven 鳞音圣地带 | 营地 | 墓地(殉道者墓) |
| emberpass 烬石隘口 | 营地 | 林野(焦林) |
| fireridge 火脊巢穴 | 营地 | 林野(硫磺灌木) |
| forge-works 熔铸工坊 | 营地 | 水域(冷却渠) |
| dragonmaw 龙渊之心 | 无 | 墓地(祭品骸骨)、营地(教团营垒) |

  新地形的风味名由施工方从副本主题里取,两到三个就够;不新增事件文本。

### 1.2 路况双刃

| 路况 | 坏处 | 好处 | 解除 |
|---|---|---|---|
| 湿透 | 受疗 ×0.9;**挂上时**泡坏 1 瓶治疗药(只扣一次) | 火抗 +0.15(版图二的灼热地形用得上) | 营地 |
| 阴寒 | 攻击 ×0.92 | 敌方攻击间隔 ×1.1(冻慢) | 圣所 |
| 疲惫 | 休整回复 ×0.5 | 本趟经验 ×1.2 | — |
| 迷途 | **下一层**全盲,只持续一层 | 后两层若有暗道,无视档位直接显示 | 走过一层后自动解除 |
| 暴露 | **下一场**战斗敌方攻击 ×1.15,只持续一场 | 那一场掉落率 ×2 | 打完一场后自动解除 |
| 惊动 | 后续层精英权重 ×2(**真权重**,见 1.3) | 精英回报已提高(见 1.3) | — |

- `RouteCondition` 新增 `upside` 字段(与 `battle`/`map` 同构),`desc` 同时写清坏处与好处。
- 新增 `expires?: 'next-battle' | 'next-layer'`,由 sim 层在打完一场或走过一层时移除,并写一条可见的「××消退」结果条。

### 1.3 精英

- 回报:金币 ×2、经验 ×2、熟练度 +2(普通战 +1),掉落率保持 24%,掉落**品质下限提一档**(至少绿)。
- 惊动的实现改成真权重:后续每个战斗节点翻成精英的概率 = `基础精英率 × 2`,基础精英率取地图生成时的精英占比(约 0.15–0.2),而不是现在的 50%。`eliteWeightMult` 接进去,不再是死代码。

### 1.4 迷雾起点

首次进副本(档 0)时,**相邻一层的节点显示地形**,不显示名字、类型和内容。更远的层仍然是「?」。迷途发作时下一层照旧全黑(U30)。

### 1.5 撤退代价

主动撤退(休整中直接回城,或战斗中下撤退令后成功撤离)时,**本趟已获得的金币和熟练度只保留一半**(向下取整),装备照拿,药水照退。结果屏写明「撤退:金币 −X、熟练度 −Y」。团灭不在此列,照旧走原逻辑。

### 1.6 bug 修复

逐条对应 §0 的 R1 bug。

1. 湿透只在**挂上的那一刻**扣药。
2. 暴露、迷途按 1.2 的 `expires` 自动消退。
3. 惊动按 1.3 改真权重。
4. 暗道:档 <3 时完全不显示,既没有「???」也没有跳层线。迷途的好处除外。
5. `autoPickNode` 读 `revealTier(m, bonus, penalty)`,同时吃迷途惩罚;档位够时优先宝箱和能解除当前路况的地形。逻辑留在 sim 层。
6. Boss 节点不掷路况。

**验收(vitest)**:

- 湿透从挂上到本趟结束只扣 1 瓶药。
- 暴露打完一场后消失,迷途走过一层后消失。
- 惊动下 500 个种子的精英翻转率在 `基础率×2 ± 5%` 以内。
- 档 0、1、2 下,渲染数据里都不含暗道节点。
- 每个副本都有 ≥2 种风险地形;Boss 节点不触发路况。
- 撤退后,本趟金币和熟练度各剩一半;团灭不受影响。
- 探针重跑:风险最高的路线与最低的路线,按「回报 − 风险」折算后的差距,要小于两者在本轮之前的差距。施工方在 HANDOFF 写明前后数字。

## 2. R5.2 R2 尾款:真状态机 + 战斗界面拆出(U33⑦)

- `src/ui/screens.ts` 落地真正的 `go(screen)` / `back()`,用一个 `screen` 状态取代 `screen` / `hubScreen` / `memberSheetId` 三套状态。地图、战斗、结算也成为 `Screen` 值,不再由 `run.phase` 推出来。`run.phase` 只是数据,界面由 `go` 驱动。

- **App.tsx 少于 1200 行**。行为零变,只搬结构,不夹带交互改动(U29 的纪律)。

**验收**:

- vitest:`go`/`back` 的跳转表单测,每个 `Screen` 都有返回目标,不存在死循环。

## 3. R5.3 武器:每族一个独有用处 + 按人学(U33⑤⑥)

### 3.1 五族独有用处

| 族 | 独有用处 | 实现要点 |
|---|---|---|
| 刃 | 暴击时附流血(3 秒内造成该次伤害 30% 的持续伤害) | 新增 `bleed` DoT,与灼烧分开计 |
| 锤斧 | 普攻附破甲(目标防御 −20%,3 秒);**只有锤斧的伤害累积读条打断值** | 见 3.2 |
| 长柄 | 前排越线够后排(已有);每场战斗替身后一名队友挡一次攻击 | 新增一次性 `guardOnce` |
| 弓 | 优先射击正在读条的后排;没有读条者时打残血 | 改 `allowedPool` 后的选目标,不改射程规则 |
| 杖圣器 | 施法(已有);非施法者抡杖 = 前排钝击 | 不变 |

### 3.2 打断改规则(制作人点名:「不再是任何武器的攻击都可以打断读条」)

- 现状:任何伤害都累积到读条的 `taken` 阈值(`combat.ts:568-576`)。
- 改为:**只有锤斧族的普攻和技能**按 1.0 累积。其他伤害按 **0.25** 累积(C4 占位;完全归零的话,没带锤斧的队伍会彻底失去应对手段,需要制作人自测后再定)。
- 打断类招牌技(铁壁破咒盾击、冲锋锁喉、戒律沉默)**不受影响**,照旧直接打断。
- 这一条会改变 Boss 战形态。⑨/⑲ 黄金值必然漂移,重标时在 HANDOFF 写明新旧数字和原因,不要只改阈值。

### 3.3 数据修正

- 守卫铁壁的盾墙猛击、破甲盾击:`weaponFamily` 加上 `polearm`(数据 bug)。
- 牧师的治疗类技能(圣光术、神圣新星、真言盾、虔信祷告、招牌技中的治疗)改为需要 `staff` 或 `blade`,不再是通用。拿锤斧、弓、长柄的牧师放不出治疗。
- 冲锋队长的战术转移需要长柄,而战士天生不熟练长柄:保留这个取舍,但要在技能说明里写清楚(见 3.5)。

### 3.4 按人学武器

- 公会级的 `weaponTraining` 改为成员级的 `Member.weaponLearned: WeaponFamily[]`。
- 学一族:**100 金,2 天**;训练场 Lv2 起缩短为 1 天。期间该成员 `busyUntilDay` 未到,不能编入远征,花名册上显示「训练中,第 N 天归队」。
- 存档 v26:旧档的公会级已学族,迁移时发给每位在世成员;删除公会字段。
- 训练完成写入该成员的个人生平(R4 生平落地后接上;R5 先写一条编年史)。

### 3.5 装备前可见

- 仓库列表、装备下拉:显示武器族图标与名称;对当前成员标「✔ 熟练」或「⚠ 非熟练」。
- 装备下拉悬停:列出「换上后失去:××、××」(读 `skillFamilyBlocked`)。
- 技能列表(`skillLine`):标注所需武器族;当前被封锁的技能显示为灰色,并写明原因。

**验收**:

- 探针重跑:每个职业在本命族之间换装,至少有一个遭遇的胜率或时长差 >25%;牧师拿锤斧放不出治疗。
- 只有锤斧的伤害能把读条打满阈值(其他按 0.25);打断类招牌技不受影响。
- 守卫铁壁拿长柄能放盾墙猛击。
- 成员学族期间不能出征;v25→v26 迁移后,每位在世成员拥有原公会已学族。
- e2e:仓库列表显示武器族,装备下拉出现「换上后失去」。

## 5. R4 新顺序(U33⑩)

R5 完成并经制作人自测后进入 R4,内部顺序如下:

1. **生平**:大事记只留里程碑,其余写进 `Member.bio`。说书人故事、伤疤、武器学成、心愿、羁绊里程碑都写进当事人的生平。事实账本里的 scar、first-kill、bond-star 改为永久保留,或者在修剪前抄进 bio。
2. **设施各管一套玩法**:铁匠铺、疗养所、训练场、酒馆、祠堂,按 redesign §6 的表施工。
   - **疗养所按 U32 条目一实装**:治疗成功时创伤降一档(重伤 → 轻伤 → 虚痕)。虚痕不减属性,4 个公会日后自动消退,消退时写一条可见通知。轻伤治疗失败照旧有 15% 恶化,重伤治疗失败只是无效。`Scar` 新增 `faint` 状态,存档随 R4 升 v27。
   - **训练场**:接 3.4 的按人学武器,再加替补经验追赶。
3. **酒馆情报与假信息**(U30):接上 `revealBonus`,情报可以掺假。
4. **王国委托**:给装备、人物和解锁;信任度改为王国货架。
