# 装备成长曲线重排提案(U39 #7.4,材料非拍板——等 G2 数据与 G3 窗口)

> 制作人反馈③:「刷 2-3 次装备掉落就支持随便刷这个副本,词条问题很大,数值成长有很大问题。」
> 本文=机理诊断+调法菜单;**全部 C4,等 G2 外部数据与全量测试意见书一起定稿**,不在本窗口单方面动数值。

## 机理诊断(为什么 2-3 刷就毕业)

1. **掉落频率**:杂兵 8% 触发+精英概率 ×2+保底绿;一次远征 6-8 场≈期望 1+ 件,精英必掉 5/5(⑳ 记录)→两趟≈4-6 件,T1/T2 池 21 件基底很快凑齐「可用套装」。
2. **词条区间宽**:#2.1 tier 化后 T1[2,6]→T2[4,9]→T3[6,11];品质乘数 0.9-1.25。roll 到高段=白赚一档,玩家实际数值线远高于「期望线」——门禁 ⑲ 门考 12→10s、杂兵防秒 7→6 的重标史就是这条线的证明。
3. **无掉落衰减**:同一副本刷 N 遍,掉率/词条预算不变——「熟练度」只影响地图认知不影响收益,重复刷=纯正向。
4. **评分没有对手**:powerScore 上涨没有「需要更强才打得过」的门槛压制(expectedLevel 静态,rating 全图常数)。

## 调法菜单(可组合;每项独立可回滚)

- **A 掉落 pity 拉长**:保底计数改「副本全局步进」而非每次 roll 独立(每刷一遍, pity+1,保底绿从第 3 遍开始)——压「两趟毕业」的第一杠杆。
- **B 词条区间收窄**:T1[3,5]/T2[5,8]/T3[7,10](砍高段彩票感,上限压 10-15%);品质乘数压到 0.95-1.15。
- **C 收益衰减**:同副本重复刷,金币/经验/掉率 ×(0.9^遍数,下限 0.5)——配合 #7.3 条款词缀化「要收益去开条款」,把「随便刷」变成「选难度」。
- **D 门槛压制**:精英/门考遭遇按 expectedLevel+装备评分动态 +rating——「毕业装备」刷完,下一副本的门考依然要打(把 ⑲ 门考从 10s 收回 12-15s)。
- **E 分解产出重定价**:星髓/折金比率与重铸成本联动,让「刷出垃圾」有出口但不等价于毕业。
