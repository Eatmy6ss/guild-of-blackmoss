| 问题 | 修复后的行为 | 主要文件 |

| 重开残留资产 | 清空星髓、待赎遗物、建筑、日期、塔纪录、编年史、事件后果与增益，以及训练资格和临时战斗状态；停止旧挂机回调 | App.tsx |
| 四件套不可达 | 适配现有武器/防具/饰品三槽，改为 2/3 件触发；灰冠仍为伤害 +5%/+10%，猎风仍为暴击 +3%/+6%；角色面板同步 | App.tsx、sim/combat.ts |
| 特权训练没有入口 | 公会基地购买：150 金；不能重复囤积；下一次远征全部胜场经验 +25%，出征消费一次；未使用资格可读档保留 | App.tsx、sim/run.ts、state/save.ts |
| 心愿误判装备 | 查询装备基底实际 tier，T2 和 T3 对应槽位均满足“至少 T2”，不再依赖 ID 命名 | sim/wish.ts |
| 特性被重抽 | 已有特性保留，仅给空缺成员尝试生成；新特性同步成员状态并记入编年史 | sim/member-traits.ts、App.tsx |
| 冷静变成免疫 | 目击阵亡的士气损失减半，保留原有性格/种族系数及默契记录 | sim/morale.ts、App.tsx |
| 幸运儿收益不符 | 幸运儿 +2 个百分点、拾荒 +4 个百分点，两个来源合计 +6；同来源不按人数叠加；阵亡成员不贡献 | sim/member-traits.ts、App.tsx |
| 嗜功漏掉精英 | 战斗敌人携带明确精英标记；嗜功对精英或 Boss 加伤 8%，普通敌人无加成；选路精英的掉落加成也使用实际战斗标记 | sim/types.ts、sim/run.ts、sim/combat.ts、App.tsx |
