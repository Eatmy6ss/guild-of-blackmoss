## 一、定位与目标体验(宪法第一章,九问 Q1 定稿)

**一句话**:你是一支佣兵公会的会长;英雄不是棋子,是会死的人。

**目标体验四层**(Q1 定稿:原三层成立,制作人裁定补入第四层——矮人要塞精髓):
1. **指挥**——手动下本时,团长的每个决策真实地改变生死(已验证:技能曲线 0%→84%→100%);
2. **羁绊**——英雄会死,死亡有分量(纪念堂、英灵光环、默契随死者消逝);
3. **成长**——每一把结束,公会和英雄变得更强,并看见下一步(经验/升级/默契已上线,爬塔与目标链在 M1);
4. **涌现(矮人要塞精髓,制作人原话:"精髓不能失去")**——英雄有内在生活,事件与故事从模拟里长出来,
   不靠剧本靠系统。招募三路径的"随机上门人物"、未来的大事系统、出身背景文案,都是这一层的实体。
   **任何新系统的设计检验题:它能不能长出"玩家想讲给别人听"的故事?**

## 二、核心循环

招募三选一 → 编队(固定队,M1 拆混合编队)→ 手动/挂机下本 → 团灭或通关 →
分装备(词条随机 roll)→ 再出发。

- 双模式共用同一套决策系统,执行者不同(手动=团长,挂机=队长性格)——架构铁律的收益。
- 血量全程延续 + 战间歇整 30%;战斗死亡=永久牺牲,团灭=整队入纪念堂。
- 岔路取舍:险路(多战斗多收获)vs 稳路(少一场杂兵)。

## 三、设计红线(违反即返工)

1. **数据表铁律**:职业/性格/词缀/boss 机制/掉落表/副本/事件全部是数据表,引擎只解释数据。
   (验证:D15 调参轮全程零代码改动,只动 `src/data/`)
2. **KPI:手动模式下每 30–60 秒一个有意义决策。** boss 机制必须映射到团长指令:
   红圈→分散、咏唱→集火打断、增援→切换优先级、束缚→撤退赌博、狂暴→爆发药时机。
3. **挂机不许白给也不许白赢**(Q6 定稿):普通副本挂机=队长性格代打;爬塔挂机允许但
   胜率压在低位(稳定低层数),极限层数属于手动。
4. **失败要温柔,死亡要疼;塔内分层残酷**(Q4 定稿):普通副本撤退保护兜底、永久死亡不可撤销;
   爬塔高层(草案:9 层起)保护失效/限制,真死真损失——高风险高回报是塔的根基。
5. **随机性规则**:boss 掉什么固定(掉落表),词条好坏掉落时 roll;首杀保底一件(D14)。
6. **招募有代价**(Q9 定稿):三条路径——随机事件上门/定向悬赏/资源抽取——加内置冷却,
   且必须防软锁(存活 <3 时冷却加速或保底免费一次)。

## 四、已验证的设计事实(M0+D15 证据,置信度:高)

| 事实 | 证据 |
|---|---|
| 指挥台的价值可以被量化 | 技能曲线:塔尔玛 零指挥 0% / 中位 84% / 会玩 100% |
| 节奏体感 | 杂兵 9–11s / boss 20–28s 被制作人认可("现在的节奏不错") |

## 五、已确认的核心问题与现状

**制作人原话(M0 硬线 B):"没有给我明天想继续打开玩的冲动,成长路线有点不够明确。"**

三缺口现状(M1 P0 推进中):
1. 英雄不会成长 → **已上线**(经验/升级/默契/战力分/结算页,M1 P0 切片1)
2. 没有"下一步"的可视化 → **部分**(结算页已做;目标链/公会总览待做)
3. 世界静态 → **待做**(爬塔/词缀分档,M1 P1)

**新记录的体验级问题(D15 试玩,九问 Q2/Q3)**:
- 塔尔玛依然"轻松"→ boss 数值不再单独磨,推迟到"5 张图"里程碑逐副本设计;
- **全体角色"没有操纵感"** → 大项"体验感优化"(与地图/boss 设计捆在一起),M1 排期。
