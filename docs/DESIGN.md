## 一、定位与目标体验

**一句话**:你是一支佣兵公会的会长;英雄不是棋子,是会死的人。

**目标体验**(置信度:高,M0 全程按此执行):
- 玩家的快乐来源有三层,缺一不可:
  1. **指挥**——手动下本时,团长的每个决策真实地改变生死(已验证:技能曲线 0%→84%→100%);
  2. **羁绊**——英雄会死,死亡有分量(纪念堂、英灵光环、"愿它一直空着");
  3. **成长**——每一把结束,公会和英雄变得更强,并看见下一步(❗M0 未达成,见第五节)。

## 二、核心循环

招募三选一 → 编队(固定队,M1 拆混合编队)→ 手动/挂机下本 → 团灭或通关 →
分装备(词条随机 roll)→ 再出发。

- 双模式共用同一套决策系统,执行者不同(手动=团长,挂机=队长性格)——架构铁律的收益。
- 血量全程延续 + 战间歇整 30%;战斗死亡=永久牺牲,团灭=整队入纪念堂。
- 岔路取舍:险路(多战斗多收获)vs 稳路(少一场杂兵)。

## 三、设计红线(违反即返工)

1. **数据表铁律**:职业/性格/词缀/boss 机制/掉落表/副本全部是数据表,引擎只解释数据。
   (验证:D15 调参轮全程零代码改动,只动 `src/data/`)
2. **KPI:手动模式下每 30–60 秒一个有意义决策。** boss 机制必须映射到团长指令:
   红圈→分散、咏唱→集火打断、增援→切换优先级、束缚→撤退赌博、狂暴→爆发药时机。
3. **挂机不许白给也不许白赢**:挂机是对"不参与指挥"的模拟,应当输给会玩的团长
   (已验证:塔尔玛零指挥 0% vs 会玩 100%)。
4. **失败要温柔,死亡要疼**:撤退保护兜底"几乎不灭队",但永久死亡不可撤销、
   被束缚者可能被撤退留下——保险与代价并存(Q32)。
5. **随机性规则**:boss 掉什么固定(掉落表),词条好坏掉落时 roll;首杀保底一件(D14)。

## 四、已验证的设计事实(M0 证据,置信度:高)

| 事实 | 证据 |
|---|---|
| 指挥台的价值可以被量化 | 技能曲线:塔尔玛 零指挥 0% / 中位 84% / 会玩 100% |
| 压迫感 = 可见的机制 + 时间轴压力 | 格鲁什(红圈+震地+增援)比纯数值型 boss 更有"感";塔尔玛机制提前后时长 20–24s |
| 节奏体感 | 杂兵 9–11s/boss 20–28s 被制作人认可("现在的节奏不错") |
| 死亡有分量 | 制作人主动谈论阵亡、纪念堂;坦克阵亡会改变玩家的行为 |
| T2 装备成长显著 | 塔尔玛 21s→13.2s;但见第五节:成长"有数值"≠"有路线" |

## 五、已确认的核心问题(M0 最重要的产出)

**制作人原话:"没有给我明天想继续打开玩的冲动,成长路线有点不够明确。"**(硬线 B:未通过)

拆解出三个具体缺口(M1 的靶子):
1. **英雄不会成长**:代码里 `levelTo()` 存在但没有任何经验来源——英雄永远是 Lv5;
   击杀、下本、通关都不产生成长。
2. **没有"下一步"的可视化**:没有战力分数、没有目标链(下一个该打什么、缺什么装备),
   通关后屏幕上没有任何指向未来的东西。
3. **世界是静态的**:副本只有一座、难度无分档——装备成型后压力必然衰减(试玩反馈 #6)。

M0 的价值正在于此:**用两周回答了"循环好不好玩",并用一次诚实的硬线 B 失败
换到了"引力缺什么"的精确诊断。**
