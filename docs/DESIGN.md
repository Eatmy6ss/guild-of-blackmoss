1. **引擎:TS+React+PixiJS+Tauri → Godot 4 + HD-2D 美术方向**(八方旅人式:像素角色+3D 地匣+景深光照)。
   v1 中"引擎决策已定不换"条款自此作废;"Steam 上架 = Tauri 打包"改为 Godot 原生桌面导出。
2. **迁移策略(规格书迁移法)**:`guild-game/`(TS)整体封存为规格参考,不删不改;
   - **sim 层**:以 smoke ①–⑲ 门禁为移植规格书,先移植测试再移植逻辑(GDScript);
   - **数据表**(职业/副本/事件/装备/建筑/词缀):自动转换为 Godot 数据,内容零损失;
   - **存档 v6 schema**:JSON 原样迁 Godot 文件存档,迁移链语义保留;
   - **演出层**:按 HD-2D 重建(Godot 插件生态+AI 生成场景管线),战斗指令系统(集火/阵型/打断/前摇倒计时)为已验收设计,照搬;
   - **平衡结论**(节奏带 15-20s/35-45s、四档曲线、治疗吞吐)全部沿用。
3. **四支柱与全部红线不变**——引擎改版不触碰任何设计条款。

## 一、定位与目标体验(宪法第一章,九问 Q1 定稿)

**一句话**:你是一支佣兵公会的会长;英雄不是棋子,是会死的人。

**目标体验四层**(Q1 定稿:原三层成立,制作人裁定补入第四层——矮人要塞精髓):
1. **指挥**——手动下本时,团长的每个决策真实地改变生死(已验证:技能曲线 0%→84%→100%);
2. **羁绊**——英雄会死,死亡有分量(纪念堂、英灵光环、默契随死者消逝);
3. **成长**——每一把结束,公会和英雄变得更强,并看见下一步(经验/升级/默契已上线,爬塔与目标链在 M1);
4. **涌现(矮人要塞精髓,制作人原话:"精髓不能失去")**——英雄有内在生活,事件与故事从模拟里长出来,
   不靠剧本靠系统。招募三路径的"随机上门人物"、未来的大事系统、出身背景文案,都是这一层的实体。
   **任何新系统的设计检验题:它能不能长出"玩家想讲给别人听"的故事?**

## 二、核心循环

招募三选一 → 编队(固定队,M1 拆混合编队)→ 手动/挂机下本 → 团灭或通关 →
分装备(词条随机 roll)→ 再出发。

- 双模式共用同一套决策系统,执行者不同(手动=团长,挂机=队长性格)——架构铁律的收益。
- 血量全程延续 + 战间歇整 30%;战斗死亡=永久牺牲,团灭=整队入纪念堂。
- 岔路取舍:险路(多战斗多收获)vs 稳路(少一场杂兵)。

## 三、设计红线(违反即返工)

1. **数据表铁律**:职业/性格/词缀/boss 机制/掉落表/副本/事件全部是数据表,引擎只解释数据。
   (验证:D15 调参轮全程零代码改动,只动 `src/data/`)
2. **KPI:手动模式下每 30–60 秒一个有意义决策。** boss 机制必须映射到团长指令:
   红圈→分散、咏唱→集火打断、增援→切换优先级、束缚→撤退赌博、狂暴→爆发药时机。
3. **挂机不许白给也不许白赢**(Q6 定稿):普通副本挂机=队长性格代打;爬塔挂机允许但
   胜率压在低位(稳定低层数),极限层数属于手动。
4. **失败要温柔,死亡要疼;塔内分层残酷**(Q4 定稿):普通副本撤退保护兜底、永久死亡不可撤销;
   爬塔高层(草案:9 层起)保护失效/限制,真死真损失——高风险高回报是塔的根基。
5. **随机性规则**:boss 掉什么固定(掉落表),词条好坏掉落时 roll;首杀保底一件(D14)。
6. **招募有代价**(Q9 定稿):三条路径——随机事件上门/定向悬赏/资源抽取——加内置冷却,
   且必须防软锁(存活 <3 时冷却加速或保底免费一次)。

## 八、宪法 v3 · 角色篇(2026-09-22,grilling 共识定稿)

**总纲**:结构抄龙之信条(职阶阶梯/自由转职/Augment/混合职阶),广度抄魔兽(职业×专精),调性抄魔兽(种族=风味+轻天赋)。明确拒绝:DnD 兼职/法术位/六维属性;神界 OS2 式完全自由构筑(角色是"人"不是白板,专精身份必须可读)。参考:BG3 12 职业 46 子类 / 神界 OS2 / FFXIV 职业分家 / MH Rise Switch Skill / GW2 elite spec(扩容路径)。

**职业阶梯(三轴)**:
1. **基础层:6 职业 × 3 专精 = 18 专精,招募即带**(BG3 验证的时机;专精=同职责三种打法,机制差异化,无纯数值专精):
   - 守卫(坦克线):铁壁卫士(嘲讽格挡)/破城锤手(冲锋破甲,威胁靠伤害)/荆棘重卫(受击反伤)
   - 牧师(治疗线):圣光祭司(经典群疗)/戒律牧师(预防性吸收盾)/咏叹祭司(全队增益光环)
   - 游侠(物理远程):鹰眼神射(暴击流)/陷阱猎手(陷阱控场=束缚/减速)/兽王猎手(召唤战狼)
   - 战士(近战输出,与守卫的剑盾坦克分家):狂暴战士(双持攻速)/武器大师(重型劈砍)/冲锋队长(突进节奏)
   - 法师(奥法输出):火焰法师(高爆单发)/冰霜法师(减速控场)/奥术法师(弹幕连击)
   - 术士(暗影契约):恶魔术士(召唤小鬼)/痛苦术士(诅咒易伤)/毁灭术士(暗影弹)
2. **精进层(DD 阶梯的成长面)**:Lv6 训练场解锁,精进时 **2 个新技能选 1**(MH Switch Skill);解锁易(便宜)、**切换偏重**(金币+祝福按次收,防横跳);精进状态按专精记录,转混合暂替、切回恢复
3. **混合层:15 混合职阶 = 六基础全配对 C(6,2)**(DD 原味),默契解锁(层解锁后可转任意混合)+高品质招募可遇;招牌机制全走同一套效果引擎(护盾/反伤/诅咒/召唤/附魔/束缚),主职归属逐个定:
   圣盾使(守×牧)/游猎卫(守×游)/裂阵者(守×战)/符文骑士(守×法)/缚魂卫(守×术)/咒印手(牧×游)/辉光法师(牧×法)/契灵祭司(牧×术)/战地牧者(牧×战)/魔弓手(游×法)/蚀箭手(游×术)/游击刃(游×战)/战斗法师(战×法)/血武士(战×术)/咒火术士(法×术)
4. **通用战技(DD Augment)**:祝福在训练场学被动强化,**跨专精携带**——换行当不是从零开始
5. **身份叙事(BG3)**:每个专精一句身份句,招募卡展示

**明确留位(不进 v1)**:主动技能池(OS2,防专精身份打糊)、牧师分家(FFXIV 暗影牧,防"治疗稀缺"杠杆消失)、圣骑士/盗贼(第 7/8 基础职业扩展位)、GW2 elite spec 式资料片扩容

**种族(WoW 软处理)**:六族起步——人类/矮人/高等精灵/兽人/亡灵/血精灵;每族专属名字池+身份句+一条轻被动(数值压在平衡门禁精度以下:人类+5%经验/矮人+2防/精灵+2%暴击/兽人+4攻/亡灵士气冲击减半/血精灵+5%治疗量);招募随机生成,无职业限制;亡灵的公会登场叙事单独设计。

**装备(职业落地后接,制作人定)"连专属装备"**:词条 8→16+(受治疗量/暴伤/破甲/威胁加成/药效加成,T2 上限拉高一档)+ 基底 6→20+(每槽每 tier 2-3 个,基础盘风格化:高攻少词条/均衡/多词条)+ **专精专属武器**(掉落表按专精重排)。

**实现顺序(制作人定)**:职业系统优先(数据表→引擎效果→训练场/招募 UI→门禁),装备随后。

## 九、宪法 v3.1 · 角色篇修正案(2026-09-22,grilling 拍板)

**同构问题的根解 = 先砍后补**:
1. **基础专精 18→12**(每线 2):砍掉纯数值/换皮差 spec——破城锤手、咏叹祭司、陷阱猎手、狂暴战士、奥术法师、毁灭术士;保留 12 套真机制 kit。**制作人明示:后续肯定要补回来**——补回的前提是新机制落地(位移/引导咏唱/连击资源),不再以换皮形态回归
2. **混合职阶 15 套暂撤(dormant)**:数据保留在 `data/vocations.ts`,不进招募/训练场/门禁计数;回归条件=效果引擎补强后以真机制形态回归。回应制作人"守卫就只能是守卫,太笨拙"——职阶的灵活性以真机制混合的形式回来,而不是数值混合
3. **种族×职业限制矩阵(新增,制作人构思)**:每个种族可选职业不同——兽人无法师、亡灵无牧师。矩阵(6 线中每族 3-6 条):
   - 人类:全部 6 线
   - 矮人:守卫/牧师/战士/游侠
   - 高等精灵:牧师/游侠/法师/术士
   - 兽人:守卫/游侠/战士/术士
   - 亡灵:游侠/战士/法师/术士
   - 血精灵:牧师/游侠/法师/术士
   **与治疗保底的冲突解法**:兽人/亡灵不能当牧师,但治疗保底优先级更高——保底触发时候选种族改从"牧师可用种族"中 roll(矮人牧师来上门,合理)
4. 精进池 36→24(12 保留 spec × 2);存档消毒:读档时发现被砍 spec 自动回落 defaultSpec

## 十二、宪法 v3.3 修正案 · 副本熟练度与战争迷雾(2026-09-22,制作人构思定稿)

**逐段选路的最终形态 = 熟练度迷雾**(取代"明牌选项"初版):
- **副本内部图固定**(节点图+节点身份由数据表定义,名字→内容全服一致)——这是熟练度有意义的前提
- **未探索节点只显示风味名**(下水道/甬道/天花板),背后是事件还是灭团战斗,看命
- **熟练度按副本累积**(公会存档字段):每次深入/每个首次踏过的节点 +熟练度;阈值——低熟练:全迷雾;中熟练:显示节点类型(战斗/事件/休整);高熟练:完全揭示(具体怪组/事件内容);**满熟练:解锁「直捣 boss」选项**
- **因选择而灭团是合法结局**——无知即风险,知识即成长;这同时给挂机连刷赋予意义:每一轮都在学地图
- **挂机自动选路与熟练度联动**:高熟练按知识择优;低熟练只能按节点名"猜"(盲选)
- 存档:v9 增 `dungeonMastery: Record<dungeonId, number>`(与已踏节点集合)
