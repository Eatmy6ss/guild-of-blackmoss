# boss 机制提案书(呈制作人过目)

> 流程约定(2026-09-23 反馈④确立):**每个 boss 的机制设计先出提案,制作人过目点头后再实装**。
> 本文档为存量 8 boss 的补呈报 + 后续新 boss 的提案模板。反馈直接批注在本文档。

## 现有机制类型库(10 种,应对教学已进手册 boss 机制图鉴)

| 类型 | 应对 | 登场保障 |
|---|---|---|
| telegraph-aoe 读条范围技 | 切【分散】站位大幅减伤 | 首轮 10s,每轮循环 |
| cast-buff 强化咏唱 | 累计伤害打断 | 首轮 9s |
| cast-heal 治疗咏唱 | 打断,否则敌全体回血 | 首轮 9s |
| slow-touch 霜寒被动 | 治疗兜底,前排减速 | 普攻附带 |
| pull 拉拽 | 救援被拽者归位 | 首轮 12s |
| ground-zone 地面效果区 | 读完条瞬间保持【分散】脱身 | 首轮 15s |
| phase-invuln 相位无敌 | 别浪费爆发,转火小怪 | 首轮 20s |
| summon 召唤增援 | 及时切火 | 血量线 或 26s 兜底必出 |
| bind 束缚 | 治疗药/减伤备好 | 血量线 或 26s 兜底必出 |
| enrage 狂暴软墙 | 全力压血,别拖延 | 定时触发 |

## 存量 boss 机制明细(8 只)

### 黑苔沼泽
- **沼泽食人魔·格鲁什**(门考):震地猛击(telegraph-aoe)/呼唤蛙人(summon,半血 2 只)
  - 设计意图:教程 boss——学会分散与切火。狂暴无,容错高。

### 深渊祭司·塔尔玛(黑苔毕业考)
- 唤起腐狼(summon,75%)/虚空咏唱(cast-buff,打断门槛 110)/深渊束缚(bind,60%)/狂暴软墙(enrage 14s,×1.78)
- 设计意图:指挥考试——打断/集火/药水三课。节奏重校准:血 2450/攻 14(防 80s 狂暴拉锯)。

### 锈坑矿道
- **矿脉吞噬者·掘锚**(毕业考):坑道坍塌(telegraph-aoe)/岩钉钩索(pull,后排拽前排 60s)/唤出蝠群(summon,65%)/过载运转(enrage 29s ×1.7)
- 设计意图:拉拽教学——后排不再绝对安全,威胁表价值具象化。

### 灰烬旧战场
- **破誓大公·摩尔德雷克**(毕业考):葬仪横扫(telegraph-aoe)/亡者号角(cast-buff)/亡者相位(phase-invuln,每 30s 免疫 3s)/唤起怨灵(summon 60%)
- 设计意图:爆发管理——无敌期别交爆发,转火小怪。

### 白霜墓园
- **霜裔织法者·薇尔霍拉**(毕业考):霜寒裹尸布(slow-touch 35% 减速)/冰葬风暴(telegraph-aoe)/凛冬之怒(enrage 20s ×1.7)
- 设计意图:减速压力下的资源管理;寒鸦冰箭(敌方 frost-nova)处 dormant 待调。

### 渊底祭坛
- **深渊主教·马尔萨乌斯**(毕业考):血契共感(cast-heal,全体回 160)/唤起饿殍(summon 65%)/渊语圣歌(cast-buff)/深渊降临(enrage 21s ×1.75)
- 设计意图:治疗咏唱首秀——"快打断,它在治疗全家"。

### 荆棘要塞(5 人团本)
- **掌旗官·科尔特**(门考):战鼓冲锋(telegraph-aoe)/亲卫旗(summon)/血污旗阵(ground-zone,分散脱身/打断 200)/破胆战吼(cast-buff)
- 设计意图:团本入门——四类应对全考,分散时机更严格。
- **割据团长·维克托**(毕业考):长枪风暴(telegraph-aoe)/断头锁链(bind)/征募令(summon)/困兽之斗(enrage)
- 设计意图:团本毕业——全机制混编,速杀路线与稳打路线皆可行。
